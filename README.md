# 🍿 Snackr

[![Build and test](https://github.com/isidore/snackr/actions/workflows/build-and-test.yml/badge.svg)](https://github.com/isidore/snackr/actions/workflows/build-and-test.yml)

**[Open Snackr](https://isidore.github.io/snackr/)**

Hungry, but not sure what for? Snackr uses your location to suggest up to 10 varied snacks you can walk to right now.

## Run it

| Script                | What it does                                  |
| --------------------- | --------------------------------------------- |
| `./run.sh`            | Runs the app locally and opens it             |
| `./build-and-test.sh` | Installs dependencies, runs the tests, builds |
| `./tidy.sh`           | Formats the code with Prettier                |

## Data

Places and hours come from [OpenStreetMap](https://www.openstreetmap.org/copyright). Snack ideas and prices are guesses based on the type of place, not menus.
